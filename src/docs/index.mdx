# ThemeToggle

The central component of `react-color-scheme-switch`.
Most basically (without attached behavior),
it just looks like this:

```jsx
<ThemeToggle />
```

<ThemeToggle />

Click on it to see its three positions.
They represent (from left to right):
day/light mode, auto/normal mode, and night/dark mode.

The `onClick` event handler receives the state `'dark' | 'light' | 'normal'`.
As an example, this page 

```jsx
<ThemeToggle
  onClick={(evt, state) => {
    document.documentElement.style.colorScheme = state;
  }}
/>
```
